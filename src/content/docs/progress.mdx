## Usage

To apply this component, add the `.uk-progress` class to a `<progress>` element.

```html
<progress class="uk-progress" value="" max=""></progress>
```

<Example component="progress" index={0} />

## Theme development

On your `tailwind.config.js` file, add the
Progress component within the `ui()` plugin.

```javascript
import ui from "franken-ui";

ui({
    components: {
        progress: {
            hooks: {}
        }
    }
}),
```

### Available hooks

<span class="uk-label uk-label-primary">Note</span> If you are developing theme
from scratch, you can use all these hooks. If you're using the shadcn/ui theme,
some hooks might not work as they were already in use or removed. Learn more
about [using hooks](/docs/hooks).

| Hook Name       | Affected Classes                       |
| --------------- | -------------------------------------- |
| `hook-progress` | `.uk-progress`                         |
| `hook-bar`      | `.uk-progress::-webkit-progress-value` |
| `hook-bar`      | `.uk-progress::-moz-progress-bar`      |
| `hook-misc`     | `*`                                    |
