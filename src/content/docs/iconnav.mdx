## Usage

To apply this component, add the `.uk-iconnav` class to a `<ul>` element. Use `<a>` elements as menu items within the list and add icons from the [Icon component](/docs/icon). To apply an active state to a menu item, just add the `.uk-active` class.

```html
<ul class="uk-iconnav">
  <li>
    <a href="">
      <uk-icon icon="youtube"></uk-icon>
    </a>
  </li>
</ul>
```

## Vertical alignment

By default, the items of an iconnav are aligned horizontally. To apply a vertical alignment, add the `.uk-iconnav-vertical` class.

```html
<ul class="uk-iconnav uk-iconnav-vertical">
  <!-- ... -->
</ul>
```

<Example component="iconnav" index={1} />

## Outline modifier

To apply an outline, just add the `.uk-iconnav-outline` class.

```html
<ul class="uk-iconnav uk-iconnav-outline">
  <!-- ... -->
</ul>
```

## Theme development

On your `tailwind.config.js` file, add the
Iconnav component within the `ui()` plugin.

```javascript
import ui from "franken-ui";

ui({
    components: {
        iconnav: {
            hooks: {}
        }
    }
}),
```

### Available hooks

<span class="uk-label uk-label-primary">Note</span> If you are developing theme
from scratch, you can use all these hooks. If you're using the shadcn/ui theme,
some hooks might not work as they were already in use or removed. Learn more
about [using hooks](/docs/hooks).

| Hook Name          | Affected Classes               |
| ------------------ | ------------------------------ |
| `hook-iconnav`     | `.uk-iconnav`                  |
| `hook-item`        | `.uk-iconnav > * > a`          |
| `hook-item-hover`  | `.uk-iconnav > * > a:hover`    |
| `hook-item-active` | `.uk-iconnav > .uk-active > a` |
| `hook-misc`        | `*`                            |
