## Usage

To create a navigation with previous and next buttons, just add the `uk-slidenav` attribute to `<a>` elements. Add the `previous` or `next` parameter to the attribute to style the nav items as previous or next buttons.

```html
<a href="" uk-slidenav-next></a> <a href="" uk-slidenav-previous></a>
```

## Slidenav container

To display a conjoint slidenav, wrap the slidenav items inside a `<div>` element and add the `.uk-slidenav-container` class, as well as one of the `.uk-position-*` classes.

```html
<div class="uk-slidenav-container">
  <a href="" uk-slidenav-previous></a>
  <a href="" uk-slidenav-next></a>
</div>
```

## Position as overlay

To position the slidenav on top of an element or the [Slideshow component](/docs/slideshow) for example, just add one of the `.uk-position-*` classes from the [Position component](/docs/position). To create a position context on the container, add the `.uk-position-relative` class.

{/* Use the `.uk-light` or `.uk-dark` class from the [Inverse component](/docs/inverse) to apply a light or dark color for better visibility. */}

```html
<div class="uk-position-relative">
  <!-- The element which is wrapped goes here -->

  <a class="uk-position-center-left" href="" uk-slidenav-previous></a>
  <a class="uk-position-center-right" href="" uk-slidenav-next></a>
</div>
```

<span class="uk-label uk-label-primary">Note</span> You can also apply the
[Visibility component](visibility.md#toggle), so that the slidenav only appears
on hover.

## Theme development

On your `tailwind.config.js` file, add the
Slidenav component within the `ui()` plugin.

```javascript
import ui from "franken-ui";

ui({
    components: {
        slidenav: {
            hooks: {}
        }
    }
}),
```

### Available hooks

<span class="uk-label uk-label-primary">Note</span> If you are developing theme
from scratch, you can use all these hooks. If you're using the shadcn/ui theme,
some hooks might not work as they were already in use or removed. Learn more
about [using hooks](/docs/hooks).

| Hook Name        | Affected Classes         |
| ---------------- | ------------------------ |
| `hook-slidenav`  | `.uk-slidenav`           |
| `hook-hover`     | `.uk-slidenav:hover`     |
| `hook-active`    | `.uk-slidenav:active`    |
| `hook-previous`  | `.uk-slidenav-previous`  |
| `hook-next`      | `.uk-slidenav-next`      |
| `hook-large`     | `.uk-slidenav-large`     |
| `hook-container` | `.uk-slidenav-container` |
| `hook-misc`      | `*`                      |
