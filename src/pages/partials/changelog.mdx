**v1.0.0 (September 9, 2024)**

This update introduces lots of breaking changes and bug fixes.

**Major breaking changes:**

- Introducing Franken UI custom [JavaScript](/docs/javascript). Please refer to the documentation on how to install it. As a result, UIkit and Franken WC packages are not needed anymore.
- UIkit Icon component is dropped in favor of Lucide icons.
- Glow component is dropped in favor of a CSS-only solution.
- The `<uk-lucide>` tag has been renamed to `<uk-icon>`.

**Minor breaking changes:**

- The following components have undergone size adjustments and unification: [Card](/docs/card), [Modal](/docs/modal), [Position](/docs/position), [Margin](/docs/margin) and [Padding](/docs/padding).

**Bug fixes:**

- Fix race condition on Command component.
- Fix [Slidenav](/docs/slidenav) component.
